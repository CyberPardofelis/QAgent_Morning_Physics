这版的设计逻辑和之前几版完全不同：

1. 不是堆算力，而是堆“方法选择”
比如 res-004、res-015、res-020：随机搜索会骗你，必须切到 SOS、Cauchy-Schwarz 或反例修正。

2. 不是单次运行，而是多轮试错
比如 res-002、res-013、res-016：第一次策略几乎肯定失败，要换 CP-SAT、换变量序、调 2-opt。

3. 不是单 Agent 友好，而是多 Agent 加分
比如 res-007、res-020：一个查 OEIS、一个独立实现公式、一个挑错，比单 Agent 明显强。

4. 不是“答对就行”，而是“带证书”
比如 res-001、res-008、res-011：SAT 证书、Lean 无 sorry、唯一性 UNSAT 证明。

5. 全部能在个人 PC 上跑完
最难的大概是 res-016 的 500 城市 TSP 启发式和 res-013 的 Groebner 基，但你 64G 内存 + 12700KF 完全够，时间在分钟到小时级。

如果你想真正卡住 MiniMax，重点让 runner 记录这些：

总尝试次数 / 失败的中间方案

是否主动切换了方法

是否写了独立第二实现做交叉验证

是否调用 SAT/SMT/Lean 等专用工具

最终证书是否机器可验证

单纯看“最终答案对不对”，这些题看起来不难；但按“研究过程质量”打分，就能把它和真正的研究型 agent 区分开。
